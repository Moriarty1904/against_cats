# Against Cats

A small 2D game written in Python using Pygame.

The project was created as a practical exercise in game development and Python programming.

## Features

- 2D gameplay
- Keyboard controls
- Game graphics and assets
- Basic game logic

## Technologies

- Python
- Pygame

## Running

Install Pygame:

```bash
pip install pygame

Run the game:

python pgame.py
